About this map

We built this for our OCEANO and AG teammates to help save them some time on the FNMOC wavelet page.

The links point at fixed addresses on the FNMOC portal, where the latest run always lives, so they work the same every day. The portal itself still needs a CAC.

If something looks wrong or you have an idea for it, please send us a note with the feedback button below. The code is open at github.com/sdegan-USN/wavelet-map if your shop wants its own copy, and the rest of our Information Warfare tools are at sean.theinformed.org/iw.
